# Templite: синхронизация документации проекта

Собери текущее состояние CMS и сгенерируй `docs/PROJECT.md`.

## Шаги
1. `list_global_fields` — вкладки, секции, ключи глобальных полей и их значения.
2. `list_libraries` — библиотеки, их файлы и сколько блоков и шаблонов к ним подключено.
3. `list_components` — компоненты (тег вызова, параметры); при необходимости — `get_component_code {slug}`.
4. `list_templates` → `get_template_code {template_id}` для каждого — код, поля шаблона, библиотеки.
5. `list_block_types` → `get_block_code {block_id}` для каждого — поля и код блоков; `list_block_presets {block_id}` — пресеты.
6. `list_actions` — actions: параметры, что возвращают, к каким блокам подключены.
7. `list_pages` → `get_page {page_id}` для каждой — страницы с блоками и данными.

## Формат docs/PROJECT.md
```markdown
# {Название сайта}
> Сгенерировано project-sync. Дата: {YYYY-MM-DD}

## Глобальные поля
### {Вкладка}
#### {Секция}
| Поле | Ключ | Тип | Значение |
|------|------|-----|----------|

## Библиотеки
| ID | Название | Slug | Файлы | Где подключена |

## Компоненты
| ID | Название | Slug | Параметры | Источник |

## Шаблоны
| ID | Название | Slug | Поля | Библиотеки |

## Блоки
| ID | Название | Slug | Категория | Поля | Пресеты | Actions |

## Actions
| ID | Название | Slug | Параметры | Блоки |

## Структура сайта
### {Заголовок страницы} ({url})
- Шаблон: {название}
- Статус: опубликована / скрыта
- Блоки:
  1. {название блока} — {краткое содержание данных}
```

Сценарий только читает — сущности CMS не изменяет.
