# Templite: дизайн-бриф

## Ниша: {{niche}}

Создай `docs/DESIGN_BRIEF.md` по этой структуре.

### 1. Прочитай docs/PROJECT.md
Выпиши: нишу, аудиторию, структуру сайта, список блоков.

### 2. Разбери референсы
Поищи «{{niche}} — тренды дизайна сайтов» и разбери визуальные приёмы.

### 3. Концепция
- Стиль: минимализм / корпоративный / креативный / ретро / неоморфизм.
- Настроение: доверие, профессионализм, тепло, энергия, премиальность.
- Контраст: светлый / тёмный / смешанный.

### 4. Палитра (CSS custom properties)
| Переменная | Цвет | Роль |
|------------|------|------|
| --primary | #hex | CTA, акценты |
| --secondary | #hex | Второстепенные действия |
| --accent | #hex | Выделение, hover |
| --background | #hex | Фон страницы |
| --surface | #hex | Карточки, панели |
| --text | #hex | Основной текст |
| --text-muted | #hex | Второстепенный текст |

### 5. Типографика
- Шрифты: Google Fonts, не больше 1–2 гарнитур (подключатся в CMS как библиотека).
- Размеры, начертания и межстрочные интервалы H1–H4.
- Размер и начертание основного текста.

### 6. UI-компоненты
- Кнопки: primary, secondary, outline — скругление, отступы, hover.
- Карточки: тень, скругление, отступы.
- Формы: вид полей, состояния focus и error.
- Изображения: скругление, оверлей, соотношение сторон.

### 7. Вид блоков
Для каждого блока из PROJECT.md:
- раскладка (на всю ширину / в контейнере / сетка на N колонок);
- фон (цвет / картинка / градиент);
- расположение элементов;
- вертикальные отступы секции.

Отдельно опиши шапку и подвал — в CMS это компоненты `site-header` и `site-footer`, общие для всех страниц.

**Принципы:**
- Конкретика: цвета в hex, размеры в px/rem.
- Цельность: все блоки визуально связаны.
- Соответствие нише: стоматология ≠ IT-стартап ≠ ресторан.
- Доступность: контраст текста и фона не ниже 4.5:1.
